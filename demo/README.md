# Browser demo

After downloading the repository, open `index.html` in a browser. Alternatively, run `python3 -m http.server 8000 --bind 127.0.0.1` from the repository root and visit `http://127.0.0.1:8000/demo/index.html`. The **Overview** and **Controls & colors** links show two sample views. Use a narrow browser window to see the phone layout. GitHub itself displays the HTML source.

All labels, values, and states are invented examples. This page makes no requests to Home Assistant and has no device control. Its custom layout is illustrative; installing the theme does not install these sample cards or scenes.
